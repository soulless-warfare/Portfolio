 درباره پروژه

      
آزمایشگاه کامل با Computer Lab

      

        یک محیط آموزشی مستقل و کامل که استاد و دانشجو را به شیوه‌ای مدرن به یادگیری دعوت می‌کند.
      

    

    

      

      

        Computer Laboratory یک نرم‌افزار آموزشی مبتنی بر Python و WebView است که
        ۹ آزمایشگاه کاملاً مستقل را در یک محیط یکپارچه ارائه می‌دهد. هر آزمایشگاه با استفاده از
        HTML/CSS/JS و کتابخانه‌ی D3.js ساخته شده و شبیه‌سازی‌ها را
        به صورت گام‌به‌گام، انیمیشن‌دار و تعاملی نمایش می‌دهد.
      

      

        تمام آزمایشگاه‌ها به صورت آفلاین (Offline-First) کار می‌کنند و
        بدون نیاز به هیچ پیش‌نیاز یا اینترنت قابل اجرا هستند. پشتیبانی از
        ۵ زبان زنده دنیا، بیش از ۱۰۰ الگوریتم،
        شبیه‌سازی گام‌به‌گام با انیمیشن و
        امکان ذخیره و بازیابی پروژه‌ها از ویژگی‌های کلیدی آن است.

 آزمایشگاه‌ها

      
۹ آزمایشگاه تخصصی

      
هر آزمایشگاه شامل ده‌ها الگوریتم و شبیه‌سازی تعاملی با نمایش گام‌به‌گام

    

    

      

        

        

          

          

            
آزمایشگاه سیستم‌عامل

            
Operating System Lab

          

        

        
زمان‌بندی پردازنده (FCFS، RR، SPN، SRT، HRRN، Priority، Feedback)، مدیریت حافظه (ثابت، پویا، Buddy، صفحه‌بندی، قطعه‌بندی) و جایگزینی صفحه (OPT، LRU، FIFO، Clock).

        

          Scheduling
          Memory
          Virtual Memory
        

      

      

        

        

          

          

            
آزمایشگاه ساختمان داده

            
Data Structure Lab

          

        

        
نمایش بیتی انواع داده (int، float، double، char، string)، پشته و صف (آرایه‌ای و پیوندی)، لیست پیوندی یک‌طرفه و دوطرفه، تبدیل عبارت به Polish و ساخت درخت.

        

          Stack
          Queue
          Linked List
        

      

      

        

        

          

          

            
آزمایشگاه شبکه

            
Network Lab

          

        

        
مدل OSI، کپسوله‌سازی، سیگنال و مدولاسیون، مالتی‌پلکسینگ، فیبر نوری، تشخیص خطا (Parity، Checksum، CRC)، مسیریابی (Dijkstra، DV، LS، Flooding)، TCP/IP و پروتکل‌های LAN.

        

          OSI
          Routing
          TCP/IP
        

      

      

        

        

          

          

            
آزمایشگاه هوش مصنوعی

            
Artificial Intelligence Lab

          

        

        
الگوریتم‌های جستجو (BFS، DFS، UCS، IDDFS، Bidirectional، Greedy، A*، Floyd، Dijkstra، Prim، Kruskal)، مسائل CSP (رنگ‌آمیزی، Wumpus، N-Queens)، الگوریتم ژنتیک و یادگیری.

        

          Search
          CSP
          Genetic
        

      

      

        

        

          

          

            
آزمایشگاه پایگاه داده

            
Database Lab

          

        

        
اتصال به SQL Server و SQLite، مرور و ویرایش جداول، اجرای کوئری با حالت Dry-Run، مدیریت ستون‌ها و کلیدها، ساخت View، تشخیص خودکار درایور ODBC و مدیریت خطا.

        

          SQL Server
          SQLite
          ADO.NET
        

      

      

        

        

          

          

            
آزمایشگاه معماری کامپیوتر

            
Computer Architecture Lab

          

        

        
نمایش گیت‌های منطقی، ساخت مدار ترکیبی، جدول صحت (Truth Table)، تولید SOP، و شبیه‌ساز کامل Verilog با Parser، Simulator و رندر شماتیک گیت‌ها.

        

          Logic Gates
          Verilog
          Schematic
        

      

      

        

        

          

          

            
آزمایشگاه داده‌کاوی

            
Data Mining Lab

          

        

        
فرایند KDD، انواع داده، آمار توصیفی، هیستوگرام، Boxplot، نمودار پراکندگی، فواصل (Minkowski، Cosine)، شباهت‌سنجی، مدیریت Missing، Binning، تشخیص Outlier و نرمال‌سازی.

        

          KDD
          Statistics
          Normalization
        

      

      

        

        

          

          

            
آزمایشگاه طراحی وب

            
Web Design Lab

          

        

        
ویرایشگر HTML/CSS/JS با اعتبارسنجی ساختار HTML، Minify کردن CSS و JS، ذخیره و بارگذاری فایل‌ها و پروژه‌ها به صورت ZIP با مدیریت امنیتی کامل.

        

          HTML
          CSS
          JavaScript
        

      

      

        

        

          

          

            
آزمایشگاه امنیت و رمزنگاری

            
Security & Cryptography Lab

          

        

        
رمزنگاری کلاسیک (Caesar، Vigenère، Playfair، Hill، Rail Fence)، شبکه فایستل، DES/2DES/3DES، AES، RSA، Diffie-Hellman، ElGamal، توابع هش (MD5، SHA-256، SHA-3) و امضای دیجیتال.

        

          AES / DES
          RSA
          Hashing
        

      

    

  






  

    

      
 ویژگی‌های برجسته

      
چرا Computer Lab؟

      
قابلیت‌هایی که این پلتفرم را به ابزاری حرفه‌ای برای آموزش تبدیل می‌کند

    

    

      

        

        

        
۹ آزمایشگاه مستقل

        
هر آزمایشگاه یک ماژول کامل و مستقل با منطق، رابط کاربری و API اختصاصی است که می‌تواند جداگانه توسعه داده شود.

      

      

        

        

        
شبیه‌سازی گام‌به‌گام

        
هر الگوریتم به گام‌های کوچک تقسیم شده و با انیمیشن، رنگ‌آمیزی و توضیحات فارسی نمایش داده می‌شود.

      

      

        

        

        
چندزبانه کامل

        
پشتیبانی از ۵ زبان زنده دنیا شامل فارسی، انگلیسی، عربی، ترکی و چینی با قابلیت تغییر لحظه‌ای.

      

      

        

        

        
کاملاً آفلاین

        
تمام پردازش‌ها به صورت بومی انجام می‌شود و هیچ نیازی به اینترنت یا سرور ابری وجود ندارد.

      

      

        

        

        
ذخیره و بازیابی

        
امکان ذخیره پروژه‌ها به صورت ZIP و بارگذاری مجدد آن‌ها، با اعتبارسنجی کامل و مدیریت امنیتی مسیرها.

      

      

        

        

        
پایگاه داده یکپارچه

        
اتصال به SQL Server و SQLite با تشخیص خودکار درایور، پشتیبانی از حالت Dry-Run و مدیریت خطاهای رایج.

      

      

        

        

        
شبیه‌ساز Verilog

        
Parser کامل Verilog، Elaborator برای ساخت سلسله‌مراتب، Simulator با ADO.NET و رندر شماتیک SVG با رنگ‌بندی زنده.

      

      

        

        

        
پیاده‌سازی کامل رمزنگاری

        
از رمزهای کلاسیک تا AES، DES، RSA و توابع هش — همه از صفر پیاده‌سازی شده‌اند تا نمایش گام‌به‌گام دقیق ممکن باشد.

      

    

  






  

    

      
 معماری

      
ساختار فنی Computer Lab

      
معماری چندلایه با ماژول‌های مستقل و رابط تمیز

    

    

      

      
    
        
  • لایه نمایش (UI) – HTML/CSS/JS با WebView و کتابخانه‌ی D3.js برای نمودارها
    • 
        
  • لایه API – ۹ کلاس مستقل API برای هر آزمایشگاه با dispatch یکپارچه
    • 
        
  • لایه منطق – پیاده‌سازی خالص الگوریتم‌ها با نمایش گام‌به‌گام در قالب دیکشنری
    • 
        
  • لایه داده – SQLite داخلی + پشتیبانی از SQL Server از طریق pyodbc
    • 
        
  • لایه ابزار – مدیریت فایل، تبدیل‌ها، اعتبارسنجی و ذخیره/بازیابی ZIP
    • 
      

      

        این معماری لایه‌ای باعث شده که Computer Lab به راحتی قابل توسعه، تست و نگهداری باشد.
        افزودن یک آزمایشگاه جدید تنها با ساخت یک فایل API و یک فایل HTML امکان‌پذیر است.
